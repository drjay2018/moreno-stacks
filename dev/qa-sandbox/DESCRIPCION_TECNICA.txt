Proposito: Actualizacion de contrato de venta

1. RESUMEN EJECUTIVO
---------------------
DLAB CRM Inmobiliaria es una plataforma web de gestion integral para empresas
inmobiliarias. Combina funciones de CRM, analitica de negocio, gestion de
ventas, cobros, comisiones, marketing y reportes con dashboard en tiempo real.

La aplicacion esta disenada como una solucion de escritorio distribuible como
ejecutable (.exe) o desplegable via Docker, con base de datos SQLite local
compatible con Power BI para exportacion de datos.

2.3 Seguridad Implementada (OWASP)

  - Proteccion contra fuerza bruta (bloqueo por intentos)
  - Rate limiting configurable por endpoint
  - CSRF protection en formularios HTML
  - Headers de seguridad OWASP (X-Frame-Options, CSP, HSTS)
  - Cookies de sesion HttpOnly + SameSite=Lax
  - Encriptacion de campos sensibles (Fernet/AES) - ACTIVADO
  - SQL Injection prevencion (queries parametrizados)
  - Verificacion de integridad de DB (HMAC-SHA256)
  - Validacion de contrasenas (min 12 chars, complejidad)
  - PRAGMAs SQLite reforzados (WAL, foreign_keys, secure_delete)
  - Proteccion contra open redirect
  - Auditoria con firma hash
  - Diccionario de identidades cifrado (Excel password-protected)

4.3 PRAGMAs de Seguridad SQLite

  PRAGMA journal_mode=WAL           # Write-Ahead Logging
  PRAGMA synchronous=NORMAL         # Balance rendimiento/seguridad
  PRAGMA cache_size=-64000          # 64MB cache
  PRAGMA foreign_keys=ON            # Integridad referencial
  PRAGMA secure_delete=OFF          # Preservar datos para auditoria
  PRAGMA temp_store=MEMORY          # Temporales en RAM
  PRAGMA mmap_size=268435456        # 256MB memory-mapped I/O
  PRAGMA busy_timeout=5000          # 5s espera si DB bloqueada

6. MODULOS DE LOGICA DE NEGOCIO
----------------------------------

6.1 FinancialEngine (core/financial_engine.py)

  - Estructuracion de ventas
  - Calculo de pool de comisiones
  - Distribucion Fortune
  - Retenciones fiscales
  - Utilidades financieras

6.2 LeadsEngine (core/leads_engine.py)

  - Evaluacion y recategorizacion de asesores
  - Analisis de rendimiento

6.3 Autenticacion y Seguridad

  - Sesiones basadas en cookies
  - RBAC (Role-Based Access Control): Admin, Gerente, Asesor
  - Proteccion contra fuerza bruta (in-memory + DB)
  - Rate limiting configurable
  - Validacion de contrasenas fuertes

6.4 Exportaciones

  - Power BI: Parquet, JSON, Excel (via ODBC directo a DB)
  - AI/ML: CSV anonimizado + diccionario cifrado
  - Historico operativo: Excel completo (9 hojas)
  - Compatibilidad: Power BI lee DB sin cifrar, columnas sensibles cifradas con Fernet

6.5 Conector Power BI

  Metodo: ODBC (sqliteodbc_w64.exe incluido)
  Ruta DB: %APPDATA%/DLAB_CRM/data/dlab.db
  Relaciones:
    compromisos.cliente_id       -> clientes.id
    compromisos.proyecto_id      -> entidades.id
    transacciones.compromiso_id  -> compromisos.id
    cobros.cierre_id             -> transacciones.id
    pagos.transaccion_id         -> transacciones.id
    incidentes.cliente_id        -> clientes.id

  NOTA: Power BI tiene acceso directo a la DB. Solo usuarios autorizados
  en la misma maquina Windows pueden acceder via ODBC.

6.6 Integraciones

  - Google Calendar: OAuth2, sincronizacion de eventos
  - Dropbox: Enlaces de archivos
  - SMTP: Notificaciones por email
  - GitHub Releases: Auto-actualizacion
